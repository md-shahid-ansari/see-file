# Support

Thank you for using SeeFile!

SeeFile is an open-source document viewer. We welcome questions, bug reports, feature suggestions, and contributions from the community.

## Getting Help

If you need help using SeeFile or have a question about the project, you can use the following resources:

- **Live application:** https://md-shahid-ansari.github.io/see-file/
- **GitHub repository:** https://github.com/md-shahid-ansari/see-file
- **GitHub Issues:** https://github.com/md-shahid-ansari/see-file/issues

## Reporting a Bug

If you encounter a problem, please open a GitHub issue.

Include the following information where possible:

- A short description of the problem.
- Steps to reproduce it.
- The browser and operating system you are using.
- The file format involved.
- Any relevant error messages or screenshots.
- Whether the issue occurs on desktop, mobile, or both.

Please do not upload private, confidential, or sensitive documents when reporting an issue.

Use a sample or non-sensitive test document whenever possible.

## Requesting a Feature

Have an idea that could make SeeFile better?

Open a GitHub issue describing:

- The feature you would like.
- The problem it would solve.
- How you expect it to work.
- Any examples or references that may help.

Please check existing issues before creating a duplicate request.

## Contributing

Contributions are welcome!

If you would like to improve SeeFile, please read [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a pull request.

## Security Issues

Please do not report security vulnerabilities through public GitHub issues.

Read [SECURITY.md](SECURITY.md) for responsible vulnerability reporting instructions.

## Community Guidelines

All users and contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Before Asking for Help

Please consider checking:

1. Whether you are using the latest available version.
2. Whether the browser is up to date.
3. Whether the document format is supported.
4. Whether the issue can be reproduced with another sample document.
